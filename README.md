# The World Today — 19 November 2026

One image summing up the world news of Thursday 19 November 2026: the first
trilateral Trump–Xi–Putin summit in Shenzhen, the ICJ genocide ruling against
Myanmar, and 17 more stories from that day, drawn programmatically with Python
(PIL) so every word is crisp and legible.
